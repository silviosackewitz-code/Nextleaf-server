# Working on Nextleaf Server

This repository is public and contains only the Rust server and browser UI.
Never add native client targets, signing files, credentials or user databases.
Use English for repository prose and application text. Keep validation and GTD
rules in the backend. Preserve database migrations and sync compatibility.
Read README.md and docs/DEPLOYMENT.md before deployment changes. Run the affected
tests and production build. Never claim a release or deployment was verified
without actually checking it. Record meaningful changes in the commit description.
